# App icon

`make-app-icon.py` draws the icon: the gold horse silhouette (`horse-silhouette.png`, traced from a photo of our horse) centered in a gold ring on red.

Run from this folder: `python3 make-app-icon.py 0.62 icon.png`, then copy `icon.png` to `HAINTEL/Assets.xcassets/AppIcon.appiconset/AppIcon.png` (saved without transparency).

`make-stablepps-icon.py` draws the Stable PPs icon the same way on turf green:
`python3 make-stablepps-icon.py 0.62 icon.png`, then copy it to `StablePPs/StablePPs/Assets.xcassets/AppIcon.appiconset/AppIcon.png`.
